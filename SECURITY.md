# Security

Please report a security issue privately. On GitHub, open this repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue.

## Supported versions

The latest release is the supported version.

## Acknowledgement

We aim to acknowledge a report within three days. That is a goal, not a promise.

## Disclosure

Please give us time to fix the issue before discussing it in public. We will coordinate the timing of a fix and any public note with you.

## Scope

Reports should be about the host application, the web viewer, or the installers.
